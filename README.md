# Vox TXT

Vox TXT is a simple and accessible Android app for reading text, documents and web articles aloud.

It supports TXT, EPUB, FB2 and DOCX files. Web pages can be opened directly in the app and their main content is extracted for easier reading.

## Features

- Background reading with the screen off.
- Navigation by sentence, paragraph and section.
- Book contents when available.
- Bookmarks and search.
- Reading position saved for each document.
- Sleep timer.
- Reading time estimation.
- Recent documents and web pages.
- Separate voice settings for documents and web content.
- Saving extracted content as TXT.
- English and Bulgarian interface.

## Privacy

Vox TXT does not contain advertising or analytics. Documents, bookmarks, reading positions and settings are stored locally on the device. Internet access is used when opening web content.

## Requirements

Android 8.0 or later and a text to speech engine installed on the device.
